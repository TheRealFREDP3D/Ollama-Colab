Why This Works

Completely Free

Google Colab provides free T4 GPU access. Cloudflare Tunnels are free too. Zero cost, full power.

GPU Accelerated

NVIDIA T4 with 16GB VRAM runs 7B-13B parameter models at blazing speed with full GPU offloading.

Access Anywhere

Cloudflare Tunnel exposes your Ollama instance to the internet. No port forwarding needed.

Private and Secure

Your data stays between you and the model. No API keys, no third-party logging, no telemetry.

Any Ollama Model

Llama 3.1, Mistral, Qwen, Phi-3, Gemma, CodeLlama — pull any model from the Ollama registry.

OpenAI Compatible

Ollama's OpenAI-compatible API works with existing tools, SDKs, and chat interfaces seamlessly.

Setup in 4 Steps

From zero to a running cloud LLM in under five minutes.

1
Open the Colab Notebook
Get the notebook and enable GPU runtime

Open the notebook from GitHub. Before running anything, enable GPU runtime.

action
Go to: https://github.com/TheRealFREDP3D/Ollama-Colab Click "Open in Colab" Runtime > Change runtime type > T4 GPU > Save
Open Repository
2
Install Ollama
Run the installation cell

First cell downloads and installs Ollama. About 30 seconds.

bash
!curl -fsSL https://ollama.com/install.sh | sh
3
Pull a Model
Use the Model Browser above, or run manually

Choose a model that fits your GPU's VRAM. 7B-13B models work great on T4.

bash
!ollama pull llama3.1 !ollama pull mistral !ollama pull qwen2.5-coder:7b
Tip: Use the Model Browser above to see exactly which models fit your GPU and pull them with one click.
4
Start Cloudflare Tunnel
Expose Ollama to the internet

Run cloudflared to create a quick tunnel. You get a random .trycloudflare.com URL.

bash
# Start Ollama server in background !ollama serve & # Expose via Cloudflare Tunnel !cloudflared tunnel --url http://localhost:11434
The URL changes each restart. It only stays active while the Colab session is running.

Use the API

Once your tunnel is running, call Ollama's REST API from any application.

curl
curl -X POST https://YOUR-URL.trycloudflare.com/api/chat \ -H "Content-Type: application/json" \ -d '{ "model": "llama3.1", "messages": [{"role": "user", "content": "Hello!"}], "stream": false }'
import requests response = requests.post("https://YOUR-URL.trycloudflare.com/api/chat", json={ "model": "llama3.1", "messages": [{"role": "user", "content": "Hello!"}], "stream": False }) print(response.json()["message"]["content"])
const resp = await fetch("https://YOUR-URL.trycloudflare.com/api/chat", { method: "POST", headers: { "Content-Type": "application/json" }, body: JSON.stringify({ model: "llama3.1", messages: [{ role: "user", content: "Hello!" }], stream: false }) }); const data = await resp.json(); console.log(data.message.content);

OpenAI Compatible Endpoint

Ollama also exposes /v1/chat/completions. Point any OpenAI SDK at your tunnel:

python
from openai import OpenAI client = OpenAI( base_url="https://YOUR-URL.trycloudflare.com/v1", api_key="ollama" ) response = client.chat.completions.create( model="llama3.1", messages=[{"role": "user", "content": "Hello!"}] ) print(response.choices[0].message.content)
